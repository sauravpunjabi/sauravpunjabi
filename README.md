## 🚀 Featured Projects

### 🏎️ F1Pulse — Cinematic F1 Platform
A full-stack Formula 1 archive serving live 2026 season data and **76 seasons of history** through a cinematic, scroll-driven experience.
- Full-stack data pipeline ingesting 1950–2026 F1 history from Jolpica & OpenF1 into PostgreSQL via Prisma, with a Redis-cached REST API and BullMQ background jobs for automatic post-race updates
- WebSocket live layer with an OpenF1 circuit-breaker client broadcasting real-time positions and telemetry — every result and standing is database-driven, nothing hardcoded
- Cinematic frontend with GSAP ScrollTrigger, Framer Motion, and React Three Fiber, including 3D circuit visualizations and a History Mode that fades from black-and-white to colour as you scroll through the decades

`Next.js 14` · `TypeScript` · `Node.js` · `PostgreSQL` · `Redis` · `Prisma` · `React Three Fiber`

### 🔧 AutoServe — Vehicle Service SaaS · [Live Demo](https://auto-serve-three.vercel.app)
A multi-tenant SaaS platform for managing automobile service workflows.
- Normalized PostgreSQL schema for vehicles, jobs, and service records
- JWT authentication with role-based access control for customers, mechanics, and admins
- Service bookings, job cards, inventory tracking, and invoice generation
- Subscription-based multi-tenancy supporting multiple service-center accounts

`React 18` · `TypeScript` · `Node.js` · `PostgreSQL` · `JWT`

### 🤖 J.A.R.V.I.S — Local AI Voice Assistant
A fully local, Iron Man-inspired AI voice assistant with wake-word detection and PC control.
- Hands-free voice pipeline: wake-word detection → Whisper STT → neural TTS
- Gemini 2.5 Flash as the conversational core with persistent memory and a custom JARVIS personality
- Modular skill system (PC control, web search, weather, media) extensible without touching core
- PyQt6 desktop GUI for an always-on assistant

`Python` · `Gemini 2.5 Flash` · `Whisper` · `PyQt6`
